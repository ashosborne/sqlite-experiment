## Summary

Frame append with commit records; readers pin mxFrame snapshots via wal-index.

## Entrypoints (citations)

- `sqlite3WalFrames()` (other) — `src/wal.c:4275`, `src/wal.c:1647`, `src/wal.c:3493`

## Inputs / outputs / observables

- -wal/-shm files; readers see pre-write snapshots; PRAGMA wal_checkpoint results (busy/log/checkpointed frame counts)

## Behaviour (as implemented)

- WalOpen (src/wal.c:1647); WalFrames (src/wal.c:4275) appends page images with commit-frame marking, updating the wal-index hash tables in shm; BeginReadTransaction (src/wal.c:3493) pins mxFrame so each reader gets a stable snapshot; readers never block the writer, one writer at a time

## Validation rules found in code

- WAL header checksum chain validates frames; salt rotation on reset invalidates stale frames

## Edge cases found in code

- Recovery scans the wal after crash rebuilding the index; long-running readers pin wal growth (checkpoint starvation)
